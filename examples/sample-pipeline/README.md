# Sample Pipelines

These standalone YAML files exercise pipeline and trigger schema features
without requiring the full GitOps sample repository.

| File | Focus |
| --- | --- |
| `1-pipeline.yaml` | Simple LLM-backed pipeline with sequential goals. |
| `2-pipeline.yaml` | Goal-driven Git and environment tasks. |
| `3-pipeline.yaml` | Mixed script and goal tasks with display options. |
| `4-pipeline.yaml` | Secrets, sessions, scripts, and dependency behavior. |
| `5-pipeline.yaml` | LLM sharing controls, profiles, volumes, conditions, child pipelines, reusable-step inclusion, and knowledge context. |
| `6-knowledge-kind-comparison.yaml` | Guardrail, policy, and guideline behavior in LLM goal tasks. |
| `triggers.yaml` | Basic trigger manifest examples. |
| `all.yaml` | Broader trigger manifest examples with branch, tag, and repository filters. |

For GitOps repository layout examples, use `examples/sample-config-repo`.
