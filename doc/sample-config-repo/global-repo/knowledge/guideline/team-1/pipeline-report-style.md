  # Pipeline Report Style Guideline

  - Prefer compact Markdown tables for evidence summaries.
  - Keep reports factual and concise.
  - Mention only the command output that helps explain the result.
  - Use `ready`, `not ready`, or `needs review` as the final status wording.
  - Avoid long command transcripts unless the task explicitly asks for them.
