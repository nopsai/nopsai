# Plans

One file per task, written by the planning stage and named
`<task-id>-<slug>.md`, matching the task's permanent number.

A plan is committed to the task's own branch before any code is written, and
copied here on the base branch when the task passes review. That ordering is
what makes the record useful later: the plan on the base branch is always a plan
that was actually carried out and reviewed, not one that was abandoned.
